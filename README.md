# PVPCore 
PVP core plugin spigot/bukkit for 1.19.2 version.

Contains:
- Player profiles (spent time, stats, penalties, fights, setups, topups),
- All useful commands (player, administrator),
- Player guilds (stats, treasury),
- Player fights,
- Configuration files,
- Bukkit Adventure (gradients etc.),
- LuckPerms Hook with listeners.

Requires:
- LuckPerms,
- SkinsRestorer,
- And the MongoDB database.

**WARNING:** The plugin is not 100% finished, it may contain bugs.
